# 首页大脑模型来源

`brain-atlas.glb` 来自 [StarKnightt/brain-explorer](https://github.com/StarKnightt/brain-explorer)，使用其中固定版本 `d778b990dac88c2442ae67b83134537c0883db17` 的 `public/models/brain-atlas.glb`。

原始数据为 [OpenNeuro ds006128](https://github.com/OpenNeuroDatasets/ds006128) 1.0.11 中 `sub-01` 的 FreeSurfer 皮层表面，许可为 **CC0-1.0**。模型包括统一皮层、小脑、脑干以及脑区辅助网格；首页仅显示统一皮层、小脑和脑干。

- 完整来源记录：`brain-atlas.provenance.json`
