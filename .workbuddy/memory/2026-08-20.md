## 修复 file:// 协议下文章全部消失的问题

- 问题：上一步把硬编码数组清空后改为完全 fetch posts.json，但用户是双击打开 HTML（file:// 协议），浏览器 CORS 策略阻止 fetch 本地 JSON，导致所有文章消失
- 方案：用 `<script>` 标签加载数据（file:// 下不受 CORS 限制）
  - 新建 `posts-data.js`：从 posts.json 生成，内容为 `window.POSTS_DATA = [...]`
  - script.js 改为 `const posts = (window.POSTS_DATA ? [...window.POSTS_DATA] : [])`
  - loadRemotePosts 保留但 catch 静默（http 服务器环境下热更新，file:// 下跳过）
  - 在 index/articles/article/search/about 五个 HTML 的 script.js 之前插入 `<script src="posts-data.js?v=1"></script>`
  - script.js 版本号 +1 强制刷新缓存
- 数据源：posts.json 为唯一编辑源，posts-data.js 是生成产物（头部已注明"请勿手动编辑"）
- 校验：script.js + posts-data.js 语法均通过，5 个 HTML 均已引入 posts-data.js
